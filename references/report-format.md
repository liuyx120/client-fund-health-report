# 版式与内容安排

## 设计权威与复用方式

`assets/reference.docx` 是用户 2026-09-04 提供的完整最新手改版，仅作为版式与编排样本，内容数字不是事实库。保留源文件不修改。在任务副本上编辑，优先复制同角色段落的 `w:pPr`、各 run 的 `w:rPr`、表格的 `w:tblPr/tblGrid/tcPr`，而不是将整段赋值后丢失格式。未来新增内容按角色套格式，不按旧稿段落绝对序号盲替换。固定栏目标题可保留，月份、方向性副标题和论述必须动态更新。

参考的主要字体直接格式为“微软雅黑”，虽然 Normal 样式底层写有 Arial Unicode MS；不能只复制样式名。继承来源、eastAsia 与 latin 字体都需检查。若目标环境缺字库，报告渲染限制并解决字体映射，不能把替代字体当作已通过保真验证。

源版页面为约 A4 纵向（21.0009 × 29.7004 cm），边距上 1.4499 cm、下 1.3494 cm、左右 1.7498 cm。保留源版页脚、页码域、标题及一级标题下边框。不强制每个板块独占一页。

## 固定内容顺序

1. **标题、报告期间及日期**，直接进入正文。
2. **一、{上月}资本市场运行复盘**：`上月`始终指报告出具日所在月份之前的最近完整自然月；1月出具时对应上一年12月。权益市场（A股，按持仓需要补港股/海外）与债券市场均只复盘这一完整月份已经发生的事实及其对客户的含义。例如10月出具报告复盘9月，11月出具报告复盘10月，以此类推。
3. **二、{本月}市场观察与后续展望**：`本月`始终指报告出具日所在自然月，写截至报告日最新可得的宏观、政策、盈利、估值和流动性证据及后续观察点；尚未披露本月数据时明确使用最近已披露数据，不把上月数据写成本月已发生事实。例如10月出具报告展望10月，11月出具报告展望11月，以此类推。用最新可得数据，不强制“中性偏积极”。
4. **三、客户持仓全景梳理**：总资产概况；持仓明细与结构（六列：产品名称、投入本金万元、持仓市值万元、持有收益率、资产类别、占总资产）；穿透后的大类资产配置结构及权益行业结构；市场背景下的持仓对比（说明区间，指数表：市场、指数名称、上月涨跌幅、近两完整月累计涨跌幅）；表注；核心结论模块。指数期限可按明确用户要求变化。
   - “（三）大类资产配置结构”不能只按基金名称或产品标签归类。逐只产品采用报告日之前最新已披露季报的股票、债券、现金及其他资产占基金资产净值比例，以客户当前持仓市值加权，展示组合穿透后的权益、债券、现金及其他/未识别资产配比。正文解释主要风险来源、稳定器和未穿透部分。
   - 紧接大类资产表展示“权益行业配置（前十大重仓股识别口径）”。根据各权益相关基金最新已披露季报中的前十大重仓股，统一行业分类并按客户当前持仓市值穿透汇总。至少列示主要行业、占客户总资产比例、占已识别前十大股票敞口比例和主要来源产品；必要时补充前几大重合个股及跨基金重复暴露。
   - 行业表后用成段文字说明行业集中度、风格重叠和分散程度；不得将前十大重仓股行业分布表述为基金全部权益资产的完整行业分布。必须同时列示前十大股票敞口覆盖度或未识别比例。
   - 两张穿透表下方必须标注数据来源、报告期、检索截止日和计算口径。标准口径写明：“基金资产配置及前十大重仓股来自各基金报告日之前最新已披露季度报告；组合穿透比例按客户当前持仓市值加权估算。行业结构仅基于前十大重仓股识别，不能代表基金全部股票资产的完整行业分布。”若不同产品对应不同报告期，逐只或分组注明。
5. **四、持仓配置亮点总结**：约三段编号文字，论证保留价值，不虚构产品优势。
6. **五、下一阶段配置策略与操作建议**：依次“先定原则”“正确看待盈亏”“本月市场位置判断”“具体操作建议”“分情景应对方案”。客户盈利时不要沿用“浮亏”标题。
   - 所有调整建议必须显式承接第三部分的穿透结果，先判断权益/债券/现金等大类结构是否匹配客户目标、期限、流动性和风险承受能力，再判断权益内部行业方向是否均衡。不能只依据单只基金盈亏或产品标签提出调仓。
   - 若科技、医药、消费等单一方向在已识别前十大股票敞口中占比较高，或多只基金重仓股高度重合，应说明集中风险，并优先避免继续调入同类暴露；可通过降低相关产品、补充相关性较低的行业/宽基、增加债券或现金等方式均衡。若整体权益仓位不高或集中仅存在于已识别样本中，应保留口径限制，不能仅凭前十大持仓机械调仓。
   - 涉及具体金额时，尽量给出调整前后大类资产比例及主要行业暴露的方向性变化；无法可靠测算时写明数据限制，不编造精确调后穿透比例。
   - 具体操作先放三列表（产品/当前状态/操作建议），覆盖当前持仓的明确动作。
   - 然后“1. 存量持仓”逐只写需操作产品；无须调整者可在总览及亮点说明，避免凑小额调整。
   - “2. 调入产品”逐只成段。新产品类别不一定是固收+，根据客户要求和适配性命名。
   - “3. 操作节奏”与前面的“1. 存量持仓”、“2. 调入产品/后续新增资金安排”使用完全相同的组内小标题样式，不得套用二级标题或大号字样式。其下的“操作节奏总纲”写阶段金额、触发条件、到账及档期衔接、调后结构、执行失败备用方案。
   - 上涨、震荡、下跌三个情景各一段。
7. **六、风险提示**：先写市场风险、收益/回撤目标适配、流动性与适当性等与实际组合有关的风险，最后必须完整加入以下固定免责声明，不得删改、缩写或拆散到其他章节：

   本报告基于客户提供的持仓信息及公开数据编制，所载内容及观点仅供参考，不构成任何投资建议或收益承诺。基金有风险，投资需谨慎。基金的过往业绩及其净值高低并不预示其未来业绩表现，基金管理人管理的其他基金业绩亦不构成本基金业绩表现的保证。报告中的资产配置分析、健诊结论及调整建议均基于报告日的市场环境与持仓情况，可能随市场变化而调整，投资者不应将其作为投资决策的唯一依据。投资者在投资基金前，应认真阅读《基金合同》《招募说明书》《产品资料概要》等基金法律文件，充分了解基金的风险收益特征，结合自身的投资目的、投资期限、投资经验、资产状况及风险承受能力，独立做出投资决策并自行承担投资风险。基金管理人提醒投资者遵循基金投资 "买者自负" 原则，在做出投资决策后，基金运营状况与基金净值变化引致的投资风险，由投资者自行负担。本报告所载数据来源于公开渠道及客户提供资料，基金管理人不对该等信息的准确性、完整性和及时性作出保证。
8. **资料来源与检索截止时间**：覆盖指数、宏观、产品关键事实；用来源名称、发布日期、可点击链接，不能只写“公开市场行情”。

默认篇幅约四页：市场约一页、持仓约一页、亮点和操作总览约一页、产品操作与风险约一页，仅作为篇幅预算，不是强制分页。先精简重复话，再调内容；不删重要风险或缩小字号凑页。

## 主要市场指数的动态筛选规则

这是每次生成报告的固定要求，除非用户明确要求其他口径：

- 先从客户持仓识别相关风格、地区和行业，例如消费、内需成长、科技成长、港股、海外中国互联网、医药或新能源；不要机械沿用上期指数。
- 指数表现区间默认随报告日滚动：展示最近一个完整自然月的月度涨跌幅，并同时展示最近两个完整自然月的累计涨跌幅；如用户另行指定区间则按其要求。10月出具时默认展示9月及8—9月累计，11月出具时默认展示10月及9—10月累计，以此类推；不得沿用上期报告的陈旧月份。
- 对每个候选指数，以关联客户持仓的合理建仓窗口或用户指定区间计算同区间累计涨跌幅。只保留累计表现弱于至少一只对应客户持仓的指数，默认列3—4个；不能把与持仓无关、但表现较好的宽基指数放入表中放大客户持仓问题。
- 当家庭成员建仓日不同，先按成员或产品的关联关系筛选，再在表注中写明“指数仅作市场背景，不是家庭合并账户或单只基金的业绩基准”。不得把不同建仓期的指数收益直接与家庭合并收益率作排名。
- 每行必须写清市场、指数名称及代码、比较区间和累计涨跌幅；亏损为绿色、上涨为红色。公开数据应可追溯并在资料来源中附链接。数值无法核验时不编造精确值；可写“约”并说明估算口径，或更换为可核验的相关指数。
